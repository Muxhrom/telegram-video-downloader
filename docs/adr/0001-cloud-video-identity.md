# 用稳定标识关联云端视频

现有云端视频以可读文件名保存；同一聊天可能出现同名文件，而本地副本可以在上传后被删除。今后的新上传文件在可读名称中加入聊天与消息的稳定标识，使云端文件能准确关联视频条目。已有文件仅在上传记录提供可靠对应关系时列入批量改名候选；仅靠同名推断的文件须经用户逐项确认。旧文件改名由用户从预览清单手动启动，不在程序启动时自动执行。

在任何旧文件迁移前，须先以临时小文件在当前 OpenList 与云盘挂载上验证重命名操作，并核对改名前后路径。目标名称已存在、来源不明确或核验失败的文件跳过且不得覆盖；迁移结果保留旧名与新名的对应关系，以便检查和恢复。选择这一方式是为了在保留可读名称的同时提高去重准确性，并避免一次性处理既有云端文件时误认或覆盖。
